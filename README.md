# EduPro Research Paper

This is a static HTML, CSS, and JavaScript companion to the EduPro Analytics
dashboard. It has no package or build dependencies.

## Open the paper

Open `index.html` in a modern browser. The charts are rendered locally from
fixed, aggregate-only summaries of the 2025 validated workbook snapshot.

## Interactions

- Switch the monthly chart between counts and annual-share index.
- Select an age cohort view as count or share.
- Sort categories by enrollment volume or Category Popularity Index (CPI).
- Select category and gender-index marks to inspect the underlying aggregates.
- Use **Print paper** to print or save as PDF; **Copy citation** copies the
  suggested paper citation when clipboard access is allowed.

These controls change display only. This paper does not load the source workbook
or provide access to individual-level records. Its results are descriptive and
should be interpreted with the limitations stated in the paper.
